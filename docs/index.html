Architecture

From Parquet to Gold

Follow a record from a newly landed file to the analytics table or quarantine.

AUTO LOADER

Bronze

—

Read new Parquet files with a fixed schema and keep the source path and ingestion time. The checkpoint tracks processed files across runs.

PYSPARK

Silver

—

Check pickup and drop-off times, distance, and fare. Join valid rows to a ZIP-prefix lookup and retain unmapped rows as Unknown.

DELTA LAKE

Gold

—

Group valid trips by date, hour, and borough. The public chart uses an export of these aggregates.

Quarantine

—

Save rejected rows with their source metadata and first failing rule. This makes failures traceable and keeps those trips out of the published counts.
